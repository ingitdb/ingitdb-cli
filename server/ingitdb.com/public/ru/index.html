Почему inGitDB?

📄

Обычные файлы, реальный Git

Записи - это файлы YAML или JSON, которые можно читать в любом редакторе, сравнивать в любом pull request и клонировать с помощью одной команды git clone. Никаких двоичных blob-объектов, никакого проприетарного формата.

🔄

Полная история Git

Ветвление, слияние, поиск в истории и откат работают с вашими данными точно так же, как и с вашим кодом, потому что данные находятся в вашем репозитории кода.

✅

Валидация схемы

Коллекции определяются типизированными схемами столбцов в YAML. Команда ingitdb validate проверяет каждую запись и сообщает об нарушениях с указанием коллекции, пути файла и имени поля.

⚡

Нулевая инфраструктура сервера

Нет никакого демона для запуска. Чтение данных - это операция файловой системы на клоне git. Идеально для граничных вычислений и бессерверной архитектуры.

🤖

Готовность к ИИ через MCP

Планируемый сервер MCP будет предоставлять операции CRUD агентам ИИ через Model Context Protocol без необходимости пользовательской интеграции.

🔔

Подписчики и триггеры

Реагируйте на изменения записей через встроенные вебхуки, email, уведомления Telegram и другие каналы — или запускайте пользовательские shell-рабочие процессы с синтаксисом, вдохновлённым GitHub Actions.

Запрос и использование

CLI, Go API или агенты ИИ

Быстрый старт

Установка

# macOS
brew tap ingitdb/cli && brew install ingitdb

# Windows
winget install ingitdb

# Linux (Snap)
snap install ingitdb

# Go (любая платформа)
go install github.com/ingitdb/ingitdb-cli/cmd/ingitdb@latest

Использование

# Валидируйте директорию базы данных
ingitdb validate

# Список всех коллекций
ingitdb list collections

# Вставьте новую запись
ingitdb insert --into=geo.nations --key=ie --data='{title: "Ireland"}'

# Прочитайте запись
ingitdb select --id=geo.nations/ie
